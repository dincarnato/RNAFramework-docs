The RF MotifDiscovery module allows identifying significantly enriched sequence motifs, such as RNA-binding protein or RNA post-transcriptional modification consensus sequences, from a set of RNA regions of interest, for instance the peaks identified in RNA immunoprecipitation experiments via [RF PeakCall](https://rnaframework-docs.readthedocs.io/en/latest/rf-peakcall/).
<br/><br/>

!!! note "Note"
    Since version __2.9.8__, the core of RF MotifDiscovery has been entirely rewritten, and it now mimics the [DREME](https://pubmed.ncbi.nlm.nih.gov/21543442/) algorithm. A number of parameters have been renamed or replaced. Please refer to the table below.


# Usage

```bash
$ rf-motifdiscovery [options] -r regions.bed -f transcripts.fasta
```

To list all available parameters, simply type:

```bash
$ rf-motifdiscovery -h
```

Parameter         | Type | Description
----------------: | :--: |:------------
__-p__ *or* __--processors__ | int | Number of processors (threads) to use for shuffling (Default: __1__)<br/>__Note:__ this parameter has no effect when specified without ``-s`` (or ``--shuffle``)
__-r__ *or* __--regions__ | string | Regions BED file (mandatory)
__-nr__ *or* __--negative-regions__ | string | A BED file containing negative regions (optional)<br/>__Note:__ when no negative regions file is specified, a set of negative sequences will be generated by ``-np`` (or ``--neg-samplings``) rounds of random sampling from reference transcripts, or random shuffling if ``-s`` (or ``--shuffle``) has been specified
__-f__ *or* __--fasta__ | string | A FASTA file containing the reference transcript sequences (mandatory)
__-o__ *or* __--output__ | string | Output directory (Default: __rf_motifdiscovery/__)
__-ow__ *or* __--overwrite__ | | Overwrites the output directory if already exists
__-w__ *or* __--window__ | int | Size of the window, centered on the center of each region, in which motif discovery should be performed (&ge;3, Default: __50__)
__-np__ *or* __--neg-samplings__ | int | Number of negative sequences to generate/sample for each region (Default: __3__)
__-s__ *or* __--shuffle__ | | Negative sequences will be generated by random shuffling region sequences<br/>__Note:__ default is to sample ``--neg-samplings`` random windows from reference transcripts, for each region in the dataset
__-ns__ *or* __--nuc-shuffling__ | | Performs random shuffling of nucleotides without preserving dinucleotide frequencies
__-k__ *or* __--kmer__ | int | Fixed k-mer size (&ge;4). When omitted, every width between ``-mk`` and ``-xk`` is searched, and the best-scoring width is reported
__-mk__ *or* __--min-kmer__ | int | Smallest k-mer width to search (&ge;4, Default: __4__)
__-xk__ *or* __--max-kmer__ | int | Largest k-mer width to search (Default: __8__)
__-mw__ *or* __--max-width__ | int | Width a motif may be extended to, when a secondary regular expression is found in its flanks (Default: __``-mk`` + ``-xk``__)
__-e__ *or* __--evalue__ | float | E-value threshold to consider a motif significant (&ge;0, Default: __1e-3__)
__-nm__ *or* __--n-motifs__ | int | Maximum number of motifs to report (&ge;1, Default: __3__)
__-nog__ *or* __--no-generalize__ | | Reports the best k-mer as-is, without generalizing or refining it
__-ng__ *or* __--n-generalize__ | int | Number of regular expressions carried to the next generalization level (&ge;1, Default: __100__)
__-nf__ *or* __--n-refine__ | int | Number of regular expressions kept at each greedy refinement step (&ge;1, Default: __4__)
__-co__ *or* __--count-occurrences__ | | Counts every occurrence of a k-mer, rather than the number of sequences containing it
__-ct__ *or* __--consTolerance__ | float | Fractional tolerance to consider a position degenerate (0-1, Default: __0.2__)
__-sk__ *or* __--save-kmer-table__ | | Saves the list of k-mers, and their associated p-values, to ``kmers.txt``

## Understanding the algorithm
Analysis is limited to a ``--window`` nt-long window centered on the center of each region. A user-defined list of negative regions can be provided in BED format via the ``--negative-regions`` parameter. If no negative regions file is provided, by default, for each region in the dataset, up to ``--neg-samplings`` negative sequences will be randomly sampled from the reference transcripts. If the ``--shuffle`` parameter is specified, however, negative sequences will be generated by ``--neg-samplings`` random shufflings of the original region sequences. By default, shuffling is performed in such a way that original dinucleotide frequencies are preserved; this can be overriden via the ``--nuc-shuffling`` parameter, that enables fully-random shuffling.<br/>
Motifs are then discovered iteratively. At each iteration:

1. All the words of every searched width (from ``--min-kmer`` to ``--max-kmer``, or just ``--kmer`` if an explicit width has been specified) are counted in both the positive and the negative sequence set. By default, each word is counted only once per sequence; this can be overriden via the ``--count-occurrences`` parameter
2. The enrichment of each word is evaluated by a one-tailed Fisher's exact test, computed in log space to avoid the numerical underflow affecting strongly enriched motifs
3. The ``--n-generalize`` most significant words are taken as seeds, and generalized into degenerate IUPAC regular expressions, by introducing one additional ambiguous position at a time. The procedure is repeated, level by level, until no further regular expression improves
4. The best regular expression is extended, by searching its flanks for a secondary enriched element, up to a total width of ``--max-width``. The two elements are joined by a spacer of ``N``s, whose length is inferred from the most frequent offset between them
5. The resulting regular expression is greedily refined, by replacing one symbol at a time with each of the 15 IUPAC codes, retaining at each step only the ``--n-refine`` best replacements that improve on their parent. Steps 4 and 5 can be skipped altogether via the ``--no-generalize`` parameter
6. A p-value is computed for the resulting motif, and an E-value is derived from it by correcting for the number of tested words. If the E-value does not exceed ``--evalue``, the search stops
7. All the occurrences of the motif are erased from the positive sequences, and the search moves on to the next motif, until ``--n-motifs`` motifs have been reported

<br/>
Significantly enriched motifs are reported as Position Frequency Matrices (PFMs), in [TRANSFAC format](https://meme-suite.org/meme/doc/transfac-format.html), under the ``matrices/`` subfolder of the output directory:

```text
ID Motif_DRACW
BF RF_MotifDiscovery
P0 A C G U
1 34 9 23 34 W
2 35 0 36 29 D
3 49 0 51 0 R
4 100 0 0 0 A
5 0 65 0 35 C
6 35 24 0 40 W
7 21 20 32 28 K
XX
//
```
